Friendly labels

Link names

Give a fixed name to links, whatever name they have in the email. A rule applies to every link whose address (without parameters) contains the pattern; use * as a wildcard. If several rules match, the longest pattern wins. Shown in Journey analysis; applies immediately.

Examples: view.belfiusdirect.be = ReadOnline; belfiusdirect.be/*/contactus = ContactUs (matches /fr/contactus and /nl/contactus). A pattern without * must appear as is in the address; the protocol (https://) and the ?parameters are ignored.

Product mapping

Links the product written in the email name, the lead field Page_Origin__c and the contract field Product2__c through a common product group. A lead is attributed to an email only when the lead's group and the email's group are the same (emails whose product is ALL accept every lead). Stored in the DASH_Product_Map data extension and read by the conversions queries (02 and 04) the next time they run.

Email: a product code (CAR) means every email of that product; or a pattern on PRODUCT|JOURNEYNAME, e.g. HOM|%OWNER% (% = any text; the most specific pattern wins). Lead and Contract: the exact value, or a pattern with %, e.g. %UKP%. Values are not case sensitive. An email product can belong to several groups (VEH = CAR and MOT).

Every change is logged in the DASH_Admin_Log data extension when it exists (date, admin IP, action, setting name; secret values are never logged or displayed).
